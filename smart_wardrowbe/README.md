# Smart Wardrowbe

AI-kleerkast met dagelijkse outfitvoorstellen voor het hele gezin, in het Nederlands, met een
profielkiezer voor een gedeelde tablet. Gebaseerd op het open-source project
[Wardrowbe](https://github.com/Anyesh/wardrowbe) (MIT).

Alles draait in deze ene app op je Home Assistant: database, achtergrondtaken en de webinterface.
Zie het tabblad **Documentatie** voor het instellen.
